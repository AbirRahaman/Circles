# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** Partiful warmth and social personality, grounded by Notion's editorial discipline. Bold serif display type (Fraunces 800), tight tracking on headings, friendly sans body (Plus Jakarta Sans). Lively micro-interactions (hover lifts, press squishes, spring-curve avatar pops) give it social energy without becoming playful noise. Ocean-teal accent, warm neutrals, semantic go/maybe/no color scale. Less confetti than Partiful, more structured — Socius does games, tallies, polls, and planning, not just parties.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Neon glowing borders / multi-stop rainbow CTAs
- Floating pastel pill badges for ordinary metadata
- Decorative blob / mesh gradients behind content
- Nested scroll regions (page + card + list all scroll)
- Cartoon people waving / high-fiving / celebrating in empty states
- Huge centered illustration with no CTA
- Icons inside inputs unless functional (search, clear, password reveal)
- Soft drop-shadows as the only separator (no border)
- Disabled primary submit as the only incomplete-form feedback

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text, ≥ 3:1 for large text and UI borders
- **Touch / focus:** 44×44px minimum touch targets, refined focus rings via `outline: 2px solid var(--accent); outline-offset: 2px`

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Clear, empathetic, supportive. "Feels like friends, not a project manager." Short, conversational labels. Avoid corporate or cold phrasing.

## Icon library

- **Library:** Project SVG / inline only
- **Package / path:** Inline `<svg>` in components — no external package
- **Notes:** Stroke style, 18–24px, strokeWidth 1.8–2. One consistent style across the app. Do not mix icon sets or use emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only inline SVG icons in the project's stroke style. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
